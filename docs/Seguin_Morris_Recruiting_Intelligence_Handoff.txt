# 1. Company and Source Context
 
This document is built for Seguin Morris. The app itself is designed by CTRL Solutions and should show that credit in a professional secondary location such as the footer, About page, or Admin panel.
 
## Seguin Morris company context
 
Seguin Morris divisions include Public Utility, Energy, Telecom, Airport, Mechanical Construction, Design-Build, and Service.
 
The most relevant first recruiting target is Mechanical Construction and Service.
 
The Mechanical Construction division lists plumbing, heating and refrigeration, ventilation, and specialized systems.
 
The Service division lists HVAC, mechanical, electric, and public utilities.
 
The contact footprint includes Gatineau, Longueuil, Montreal, Ottawa, Quebec, Mississauga, Cambridge, Kitchener, Winnipeg, Edmonton, Vancouver, Detroit, Livonia, Iowa, and Barbados.

## Quebec refrigeration recruiting research context
 
The most direct Quebec hiring pool is DEP Réfrigération 5386.
 
Complementary technical pools include DEC Technologie de la mécanique du bâtiment 221.C0 and targeted AEC programs.
 
The recruiting workflow must separate construction work under CCQ from non-construction/service work.
 
The candidate vetting system must track CCQ apprentice/companion status, ASP Construction 30h, SF-1, SF-2, halocarbures, DEP, DEC, AEC, driver license, and role-specific experience.
 
School outreach should target DEP centers, cégeps, AEC programs, placement offices, stage/ATE contacts, and cohort timing.
 
The ideal student prospecting window starts approximately 90 to 180 days before completion and reactivates around 30 days before graduation.
 
# 2. Product Definition and Scope
 
The Seguin Morris Recruiting Intelligence Platform is an internal, bilingual, multi-user recruiting intelligence system. It helps recruiters find, organize, vet, rank, contact, and track qualified candidates for refrigeration, HVAC-R, mechanical service, and mechanical construction roles.
 
## Decisions
 
Internal tool only for Seguin Morris.
 
Designed by CTRL Solutions.
 
Bilingual interface, French and English.
 
Multi-user with admin levels.
 
Railway deployment.
 
Python FastAPI backend preferred.
 
PostgreSQL database.
 
Gmail for mockup/testing, Microsoft 365 later.
 
Fully automatic source collection where legally and technically allowed.
 
Swappable LLM API provider.
 
12-month inactive lead retention.
 
AI web/phone assistant planned for v2, with text mockup in v1.
 
Seguin Morris visual style and logo in the app.
 
## V1 must-haves
 
Campaign creation by role, division, region, and required qualifications.
 
Candidate lead CRM and pipeline board.
 
Source directory with source policy controls.
 
Multi-agent system for discovery, enrichment, vetting, ranking, outreach, reporting, and assistant knowledge.
 
Email-connected outreach with human approval.
 
School/program/event recruiting modules.
 
Admin settings for users, roles, branding, email provider, LLM provider, retention, and source policy.
 
Bilingual UI strings from the start.
 
Reporting dashboards for sources, campaigns, recruiters, and conversion funnel.
 
## V1 explicitly excluded
 
Autonomous hiring decisions.
 
Autonomous mass outreach without recruiter approval.
 
Full production voice assistant.
 
Full ATS replacement.
 
HR onboarding, payroll, timesheets, or employee records.
 
Immigration workflow automation.
 
Background checks.
 
## V2 parking lot
 
Voice web assistant.
 
AI phone assistant.
 
Microsoft 365 production integration.
 
ATS sync.
 
Calendar scheduling.
 
Recruiter browser extension.
 
Multi-country expansion logic.
 
Other trades beyond refrigeration/HVAC-R.
 
Candidate self-service portal.

| Reporting Agent | Track pipeline health, source performance, recruiter activity, response rates, and campaign conversion. |

# 11. Bilingual and Source Policy Requirements
 
All user-facing labels must use translation keys.
 
Supported languages are fr and en.
 
Default language should be French unless user preference says otherwise.
 
Every source must include source_type, access_method, allowed_to_scrape, notes, and last_checked_at.
 
Automated scraping must not run unless allowed_to_scrape = true.
 
If a source is not approved for scraping, use manual import, browser capture, API integration, or recruiter-assisted workflow.
